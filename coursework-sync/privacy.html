Privacy policy

Last updated: 22 September 2026

Coursework Sync is a personal tool run by its author on the author's own computer. It has one user. This policy describes what it does with data from that user's Google Account.

What it accesses

  • Google Tasks (tasks) — to create, update, complete and delete tasks in one task list.
  • Google Calendar (calendar.readonly, calendar.events) — to read coursework events and to set the colour of those events.
  • Google Drive (drive.file) — to store the homework packets the tool generates. This scope grants access only to files the tool itself creates, not to anything else in Drive.

It also reads assignments and due dates from Canvas and from Macmillan Achieve, using credentials supplied by the user.

What it stores, and where

Everything stays on the user's own computer. The tool keeps its Google authorisation token, its configuration and a record of which task corresponds to which assignment in files beside the program. Assignment titles, due dates and links are written into Google Tasks, and homework packets into Google Drive, in the user's own account.

There is no server, no database and no analytics. Nothing is transmitted anywhere except to Google, Canvas and Macmillan Achieve in the course of doing the work described above.

What it does not do

Google user data is not sold, shared, transferred or disclosed to anyone. It is not used for advertising, and it is not used to train any model.

Coursework Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Authorisation can be withdrawn at any time from the Google Account's third-party access page, which immediately ends the tool's access. Deleting the program's local files removes the stored token and everything else it holds.
