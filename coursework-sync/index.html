Coursework Sync

Coursework Sync is a personal tool that collects coursework deadlines from Canvas, Macmillan Achieve and Google Calendar and keeps them in a single Google Tasks list, so the list updates itself instead of being exported once by hand.

What it does

  • Reads assignments and due dates from Northeastern Canvas and from Macmillan Achieve.
  • Reads coursework events from the user's Google Calendar.
  • Creates, updates and removes the matching tasks in one Google Tasks list.
  • Sets the colour of coursework events on that calendar so each class is recognisable.
  • Clips the assigned problems out of a textbook PDF into a homework packet and stores it in Google Drive.

How it runs

It is a Python program that runs on its author's own computer on a schedule. There is no server, no account to create and no other user: it reads and writes only the data of the single Google Account that authorises it.
