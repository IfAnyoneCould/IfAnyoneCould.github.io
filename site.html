Point it at any simulation that takes some parameters and gives back a score, in whatever language, and it finds the parameters that score best. Right now it runs a genetic algorithm or CMA-ES.

The point is that it's easy to use. All you give it is the program and the range for each parameter, everything else has a tuned default. The goal is someone running their own sim without me there to help.

Where it's going: one binary with a local web UI, where you drop in a sim, set it up without touching json, and watch it evolve live. Then Bayesian optimization for sims too expensive to run thousands of times, picking the optimizer for you, and workers on other machines or a cluster.
